이번 세션에서 수행한 Phase 2 실험을 PHASE2_EXPERIMENTS.md에 정리해줘.

1. PHASE2_EXPERIMENTS.md를 읽어 "빠른 참조" 표의 마지막 Exp 번호를 확인하고 다음 번호를 부여한다.
2. 이번 세션에서 수정한 코드 파일, 변경 이유, 벤치마크 결과를 바탕으로 아래 필드를 채운다:
   - 날짜 (오늘 날짜)
   - 정책 (simulstreaming / localagreement)
   - 가설 (왜 이 변경이 필요했는가)
   - 변경 내용 (파일경로:라인번호 형식으로)
   - 테스트 설정 및 명령어
   - 정량 결과 (WER, latency, 영문 매치 등 — 이전 Exp 대비 비교 포함)
   - 정성 관찰 (환각, 단어 유실, 코드 스위칭, 체감 지연 등)
   - 결론 (채택 / 기각 / 수정 예정)
   - 이유 (한 줄 요약)
   - 다음 가설
3. 빠른 참조 표 상단에도 한 줄 추가한다.
4. 작성한 내용을 출력하고 수정할 부분이 있는지 확인을 구한다.

벤치마크 결과 파일이 있으면 (.omc/benchmarks/ 디렉토리) 해당 파일을 읽어 정량 수치를 정확히 옮긴다.
