## 1. 목표와 산출물 (사용자 확정 스코프)

시연에서 반복 등장할 도메인 용어·인명의 오전사를 교정할 사전 2종의 **검수용 후보**를 생산하고, 사용자 검수 승인분만 반영한다.

| # | 산출물 | 최종 반영처 | 형식 |
|---|---|---|---|
| 1 | STT 오인식 교정 후보 `candidates.csv` | `whisperlivekit/filtering/admin_replacement.json` | `[{origin, replaced}]` (origin=오인식형, replaced=정답형) |
| 2 | 번역 용어집 후보 (자료집 한영 병기 수확) | `whisperlivekit/llm_translation/admin_translation_glossary.json` | `{원어: 번역}` 평면 dict |

**채택 게이트 = 사용자 검수 단독.** 정량 회귀 스크리닝(기존 테스트셋 측정)은 수행하지 않는다(사용자 지시). 자동 필터·flag는 검수 부담을 줄이는 보조 수단으로만 쓴다.

## 3. 파이프라인

**T1. 소스 코퍼스 준비**
- 대본·개회사: 텍스트화 → 발화형 정규화(숫자·영문약어·기호) → 문장 단위 줄바꿈 `.txt`. **TTS 입력 = 정답 텍스트 = 동일 파일** 원칙.
- 자료집: 94p 렌더(2x) → 펼침면 좌/우 분할 → Windows OCR(ko-KR + en-US 2패스) 초벌 → 페이지 분류(프로필/타이틀/국문 산문/영문 산문/사진) → **한국어 산문은 렌더 시각 대조로 정제**(OCR 오탈자가 정답 텍스트에 남으면 TTS가 그 오탈자를 읽어 마이닝이 오염되므로 정제 필수). 영문은 온라인 연자 세션 분량만. 정제 우선순위: 프로필·타이틀(용어 밀도 최고) > 국문 발표문 > 나머지(시간 박스).
- 용어 인벤토리 `terms.csv`: 인명(외국인명 한글 표기 포함)·기관/부대명·전문용어·장소명 + 한영 병기 쌍(→ 산출물 2의 원천). 대본에 없는 핵심 용어는 캐리어 문장 소량 생성.

**T2. TTS 합성** — edge-tts: 한국어 보이스 2종(여/남) × 국문 코퍼스, 영어 보이스 1종 × 외국 연자 세션. 문서 단위 wav(문장 간 짧은 무음). 영문 약어·외국인명 낭독은 발화형 표기 규칙으로 통제, 고위험 항목은 사용자 스팟 청취 1회.

**T3. 경로 C 전사** — VBCable 확인 후 eval.py `--files`로 재생·전사. **`--lan auto` + diar ON(시연 동일 조건)**, 회차 2회(보이스 2종 → 문장당 실질 4샘플). 확인 포인트: eval.py의 test_data 밖 경로·정답 파일 탐색 지원 여부(미지원 시 워크트리에서 소폭 수정).

**T4. 오인식 쌍 마이닝** — `scripts/mine_replacements.py`: `metrics.normalize_text`/`_align_words` 재사용 → **연속 substitution 구간만** 추출(삽입/삭제·덩어리 환각은 `anomalies.txt` 분리) → 쌍별 빈도·출처(보이스/회차)·문맥 집계 → `candidates.csv`.

**T5. 검수 전달** — 후보에 자동 flag를 붙여 사용자 검수용으로 전달:
1. 서로 다른 run/보이스 **빈도 ≥ 2** 여부
2. **충돌 flag**: origin이 정상 텍스트(정제 코퍼스·test_data 정답·최근 전사물)에 등장 — substring 무경계 치환이므로 오폭 위험 표시
3. 초단쌍(한 글자·조사 단독) 표시
4. 용어 인벤토리 매칭 여부(우선 추천 마킹)

검수 승인분을 두 JSON에 기입(워크트리). master 머지·`/deploy-sync` 반입은 검수 시점에 사용자 확인 후 진행.

## 5. 리스크

- OCR 정제 물량 초과 → 용어 밀도 높은 페이지 우선, 시간 박스로 절단(커버리지 일부 포기가 일정보다 낫다)
- TTS 오독(이중 오염) → 표기 규칙 + 스팟체크로 통제, 잔여 위험은 검수가 최종 방어
- VBCable 불안정 → 하니스 버그는 즉시 진단·복구(fail-fast)
- en-US OCR 팩 부재 가능 → ko 단독 진행 + 영문 페이지는 시각 판독으로 대체

## 6. 스코프 제외 (YAGNI)

기존 테스트셋 회귀 스크리닝(사용자 지시로 제외), replacement 엔진 개선(무경계 substring 위험은 백로그 기록만), 형태소 기반 교정, 대량 캐리어 문장 생성, 실마이크 리허설 자동화.
