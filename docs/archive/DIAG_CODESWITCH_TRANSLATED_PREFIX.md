## 1. 증상 정의

사용자 제보(배포 환경)와 동일 형태가 dev 테스트에서 재현됨: 언어 전환 경계에서 **새 발화의 서두가
이전(잠금) 언어로 번역·음차된 1~4단어 조각으로 별도 줄 확정**된 뒤, 다음 줄에 올바른 언어의 본문이 전사된다.

```
Jong Gyeong.                          ⟨language_switch⟩   ← 한국어 "정경두"의 로마자 음차 조각 (환각 삽입)
전경두 국방장관과 저는 아 전작권 전환과 관련한 …           ← 올바른 본문
```

## 2. 원인 사슬 (코드 레벨 — 규명 완료)

1. **전환 감지의 구조적 지연**: 전환 트리거 = 침묵·화자전환 eager·스크립트-앵커(Exp-175)뿐(PLC=None, Exp-160).
   diar `ChangeSpeaker` 이벤트 자체가 ~1–2s 지연 도착하고, eager는 새 오디오 1.5s + p≥0.85 필요
   (`align_att_base.py` `_detect_language_if_needed`). 이 창(~1s, 3–4단어 — Exp-172 실측)에 방출이 계속된다.
2. **잠금 언어 강제 디코딩 = 번역/음차**: SOT에 구언어 토큰이 강제된 채 새 언어 오디오를 디코딩 →
   Whisper 멀티태스크 특성상 EN 음성+`<|ko|>`→한국어 번역, KO 음성+`<|en|>`→로마자 음차를 생성(covert translation).
3. **스크립트 신호 사각지대**: 출력 스크립트가 잠금 언어와 **일치**하므로 스크립트 반전 기반 게이트
   (Exp-168/175, 철회 구역 2의 `_is_opposite_script`)가 원리적으로 발동 불가 — Exp-172 ①′로 기록된 계열.
4. **줄 분리**: 전환 확정 시 LanguageSwitch 마커 = 하드 문장 경계 → 이미 방출된 조각이 별도 줄로 확정.
5. **철회 불가(이중 보호)**: `tokens_alignment.py` `_retract_stale_language_tokens` —
   ⓐ 조각 start가 재디코딩 창 시작(`retract_floor`, Exp-174) **이전**이면 스캔이 lower_bound에서 정지(재디코딩 재현
   불가 토큰 보호 — "You don't understand" 유실 교훈), ⓑ 스캔되더라도 구역 2는 반대 스크립트만 철회(같은 스크립트는
   직전 화자 실발화와 구분 불가라 보수 보존). 번역/음차 조각은 정확히 이 두 보호에 모두 해당한다.

**요약**: 버그라기보다, "진짜 구언어 발화를 지우지 않기 위한 보수적 설계"(Exp-171/174)의 의도된 사각지대.
해소하려면 스크립트가 아닌 신호(타임스탬프 겹침·감지 확신도 이력·diar 경계시각 대조)가 필요하다(§6).

## 5. 자동 추출의 한계 (goal Stage 0에서 개선할 것)

1. **`in_ref` 위치 무시**: 짧은 조각이 정답 다른 위치에 존재하면 REF 오판(#2), 오인식 표기 차이("도리예요"↔"돌이에요")로
   INS 오판. → 확정 라벨은 **위치 정렬(정답-전사 단어 정렬) 기반**이어야 함.
2. **같은 스크립트 중복형 누락**: 휴리스틱이 "다음 줄과 스크립트 상이"만 봐서 #3(ko 조각→ko 본문) 유형을 놓침.
3. **순차통역 소스 혼동**: bong1·kinno는 "ko 문장 → en 번역"이 **정답 자체에 실존** — 번역형 환각과 구조가 같아
   문면만으로 구분 불가. ytn2·ytn1(동시통역·전환 명확)이 이 유형의 깨끗한 관측 창.

## 6. 후속 goal 착수 시 가져갈 것

- **선행 조건**: `GOAL_BOUNDARY_QG_PRESERVE` 완료·채택 여부 확정 → **재측정으로 본 유형 잔존 확인**
  (특히 ytn2 "정경두" 경계, bong1 "플라스틱 말랑" 경계 — 재현 지점이 특정돼 있어 정성 확인이 싸다). QG-preserve가
  경계 오디오를 보존·재디코딩하게 되면 조각의 빈도·형태가 달라질 수 있음.
- **신호 후보** (스크립트 불일치를 대체/보완):
  1. **시간 겹침 대조**: 전환 후 새 언어 재디코딩 출력이 커버하는 오디오 구간과 경계 직전 구언어 조각의
     타임스탬프가 겹치면 철회 — retract_floor **이전** 토큰이라도 "새 언어 출력이 같은 구간을 재현했다"는
     증거가 있으면 지울 수 있다(§3 사례가 정확히 이 조건: `Jong Gyeong`(~54.9s)과 `전경두`(재디코딩)가 같은 발화).
  2. **diar 경계시각 소급 대조**: `ChangeSpeaker.start`(이벤트 절대시각) 이후 start를 갖는 구언어 스탬프 토큰은
     새 화자 오디오의 산물 — 지연 도착한 이벤트로 소급 철회.
  3. **감지 확신도 이력**: eager/폴백 감지의 p값·시각을 state에 남겨 저신뢰 창에서 나온 구언어 토큰만 선별 의심.
- **트레이드오프 경계**: 어느 신호든 "진짜 직전 언어 발화 꼬리" 오판 삭제(Exp-174 유실 사고의 역방향) 위험이 있어
  Stage 0에서 오탐률 실측 필수. 순차통역(kinno·bong1)이 오탐 리스크의 스트레스 테스트다 — 거기선 "ko 문장 직후 en 번역"이
  정상 콘텐츠이므로 시간 겹침 신호(1)가 가장 안전(같은 오디오 구간의 이중 디코딩만 표적).
- **분석 도구**: 추출 스크립트는 스크래치패드 전용(`analyze_lang_prefix.py`/`summarize_lang_prefix.py`, 저장소 밖 —
  Exp-172 전례)이었다. 핵심 휴리스틱은 §4 서두에 기술돼 있어 재작성 비용이 낮고, goal 착수 시
  §5 한계를 반영해 `scripts/`에 정식 구현하는 것을 권장(위치 정렬 + 같은 스크립트 중복형 포함).
