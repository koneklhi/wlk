## 4.5 추가 검증 — 짝지은 master↔브랜치 A/B (2026-07-09 오후, 사용자 요청)

"WER이 오히려 오른 것 아니냐"는 질의에 대해 같은 날·파일별 격리·선후 교대(M-B/B-M/M-B) 18런 직접 비교:

| 파일 | master R1/R2/R3 (med/max) | 브랜치 R1/R2/R3 (med/max) | 짝별 우세 |
|---|---|---|---|
| bong1 | 29.3 / 29.3 / 33.5 (**29.3**/33.5) | 27.8 / 38.4 / 29.9 (**29.9**/38.4) | 브랜치 2 : master 1 |
| ytn2 | 16.3 / 14.3 / 21.7 (**16.3**/21.7) | 18.2 / 17.7 / 15.8 (**17.7**/18.2) | master 2 : 브랜치 1 |
| sbs1 | 17.3 / 16.7 / 9.5 (**16.7**/17.3) | 11.9 / **48.2**† / 16.1 (**16.1**/48.2†) | master 2 : 브랜치 1 |

- median 합계 62.3 vs 63.7(+1.4pp), 짝별 승패 5:4 — **동일 코드 회차 간 편차(master 자체 ytn2 14.3~21.7)보다 작은 차이 = 통계적 동률**.
- **결정적 사실: 브랜치 9런 전부 게이트 발동 0회** — 이 세션에서 브랜치와 master는 동일한 디코딩 경로를 실행했고, 관측된 차이는 전부 회차 노이즈다. 게이트는 미발동 시 정규식 관찰자일 뿐이다.
- † 브랜치 sbs1 R2 48.2% = **기존 저빈도 stall 모드**(첫 40s 무출력, stall recovery 워치독 4연발, `det_lang=None`이라 게이트 동작 자체가 불가) — Exp-168에서 master에서 관측된 sbs1 48.8% stall과 동일 시그니처. 게이트 무관.
- 브랜치 bong1 R2 38.4 = 필러/웃음 변동(발동 0회, 같은 날 master도 39.3 기록). JSON: `paired_<file>_<cond>_R<rep>.json` (master=메인 `.omc/benchmarks/`, branch=워크트리).

**해석**: 게이트의 WER "비용"은 측정 한계 이하(발동 자체가 희소해 18런 짝지음에서도 0회). 게이트의 가치는 발동한 회차에서의 정성 복구(§2)이며, 발동 회차는 지금까지 전부 해당 파일의 저 WER 쪽이었다. 남은 worst-case(stall·필러/웃음)는 master에도 존재하는 기존 모드다.
